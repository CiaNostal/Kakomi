縦長／正方形の出力比率でプレビューキャンバスがじわじわ拡大し続ける不具合。**根本原因は `#previewCanvas` の
`border: 1px solid var(--ink)` が要素のレイアウトボックスに乗っていたこと**——高さ基準で決まるキャンバスが
コンテナ高さを 2px 押し上げ、`ResizeObserver` との正のフィードバックになっていた。§13.5 の対処候補のうち
**「border をレイアウトボックスから外す（最小）」**を採用し、枠線を `outline`（`outline-offset: -1px`）へ置換。
`.app-container` の高さや `.canvas-container` のサイズ指定には手を付けていない（レスポンシブへの影響なし。
`@media` 1024 / 768 の縦積みを目視確認済み）。高さ反応の `ResizeObserver` を実験的に戻しても拡大しないことを
`creep-repro.js` で確認。フェーズ4 の「幅のみ反応 `ResizeObserver`」は多重防御として残す。

## C. フレームタブ

### C-1. 超楕円スライダーを「体感で等間隔」にする

**要望:** 超楕円の次数 n をスライダーで変えると n=3〜10 で形が変わりすぎる。n が高いと変化が少なく低いと急激。
バックエンドは n 1パラメーターのまま、**UI 上は等間隔に丸くなって見える独自パラメーター**にしたい。

例（ユーザー提示）: 3〜4 は 0.2 刻み、4 以降は 0.25 刻み、さらに先は 0.5 刻み。

**現状:** `frameSettings.superellipseN`（`uiDefinitions.js` `superellipseN: { min: 3, max: 40 }`）、`frameRenderer.js` の `createSuperellipsePath`。

**検討メモ（暫定）:** UI スライダーを 0〜1（or 0〜100）の「丸さ」に、`n = f(slider)` の非線形マッピング（低次は細かく高次は粗く）を1つ用意。
状態には `superellipseN` を保存。スライダー位置を復元するためマッピングは単調＆可逆に。区分線形テーブルか `n = 3 + a * slider^k`。
